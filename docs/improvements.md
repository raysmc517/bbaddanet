# 보완점

알려진 한계와 앞으로 고칠 것을 모은다. 요구사항과 결정은 [`PRD.md`](../PRD.md)에 있고, 이 문서에는 만들고 써 보며 드러난 빈틈을 적는다.
고치면 [변경점](changelog.md)에 기록하고 이 문서에서 지운다.

마지막 정리: 2026-11-20

## 1. 데이터 범위

| 항목 | 현재 상태 | 원인 | 보완 방향 |
|---|---|---|---|
| KBO·NPB | 수집 보류 | 공식 사이트가 자동 수집·2차 이용을 금지하고, MLB Stats API의 두 리그 응답이 비어 있다 | 데이터 이용 승인 요청 또는 이용이 허용된 다른 출처 찾기 (PRD 12절) |
| 해외 리그 기록 | 선수 커리어에 없을 수 있다 | MLB API 범위 밖 | 화면 안내 유지. 해외 프로 출신의 전 소속팀은 위키백과로 표시 중 |
| 해외 리그 이적 구분 | 포스팅과 "포스팅 아님"만 나눈다 | 출처(위키백과 일본 선수 목록)가 포스팅 여부만 표시한다 | 해외 FA와 옛 임대·판매 이적(무라카미 마사노리, 이라부 등)을 나누려면 선수별 출처가 필요 |

| 마이너리그만 뛴 과거 선수 | 없음 | 과거 선수는 MLB 명단으로만 모았다 | 필요하면 범위를 따로 정한다 |
| 1990년대 초 이전 마이너리그 기록 | 거의 없음 | 원본이 거의 제공하지 않는다 | 원본 한계로 안내 |
| 국제 아마추어 계약금 | 계약일·구단은 약 2,600명, 계약금은 Pipeline 순위권 선수만 (209명) | 이동 기록에 금액이 없다 | 순위권 밖·졸업 선수는 출처가 확인되는 대로 `recruitment_overrides.json`에 추가 |

## 2. 표시와 정확성

- **구역별 추가 지표**: 타율·장타율은 구역 상세에 표시한다. 홈런·피홈런은 현재 6개 집계값에서 역산할 수 없어 별도 필드와 캐시 재수집이 필요하다. OPS는 볼넷·사구·희생플라이까지 수집하고 타석 종료 위치로 분류한 출루율의 해석을 정한 뒤 검토한다.
- **수상 전수 점검(2026-11-18) 남은 항목**: [전수 점검 보고서](awards-audit-2026-11-18.md) 중 HOF 누락 8명·연도 5명, Williams·Giménez, 2026 실버슬러거·행크 애런상, 포지션 빈 값은 11-19에 고쳤다. 남은 것: 2026 All-MLB 퍼스트 팀 Chris Sale(원본 API에도 없음, 출처를 둔 보완 자료 필요), 구단 오류(2016 GG Kinsler TEX→DET, 1995 GG Boggs BOS→NYY, 2026 All-MLB 2nd Wood CHC→WSH, 이적 선수 기준 2건) 정정 규칙.
- **MLB 구단 밖 팀으로 기록된 수상**: 원본이 WBC 대표팀(2023 Williams USA, Giménez VEN)이나 옛 구단 ID(Guerrero 3823)로 적은 행은 팀을 비워 둔다. 실제 소속 구단(MIL·CLE, 명판 LAA)은 출처를 둔 보정 자료가 있어야 채울 수 있다.
- **수상 데이터 구조**: 상·연도·리그·선수만으로 중복 제거해 J.D. Martinez의 2018 OF·DH 수상과 1959~62 올스타 두 경기 정보를 잃는다. 수상 부문·선정 시즌·회수 정의를 구별해야 한다.
- **명예의 전당 투표·명판 검증 범위**: 회원 354명 대조는 완료했지만 기자단 연도별 투표 73개 중 63개는 429 제한으로 재검증하지 못했다. 득표수 null 5명에는 특별 선출·이름 차이·결선 표 문제가 섞여 있다. 명판 팀은 빈 값 31명 외에 `No team` 54명이 있어 미제공과 실제 무로고 명판을 구별해야 한다.
- **이적 선수의 팀별 행 순서**: 원본에 경기 날짜가 없어 2023년 이전 시즌의 여러 팀 행은 이적 순서가 아니라 팀 약자 순이다. 최근 시즌(2024~)은 마지막 소속 팀만 맨 아래로 보내므로 세 팀 이상이면 앞 팀들의 순서는 보장하지 않는다.
- **리그 1위 기준**: 시즌 중 AL·NL을 옮긴 선수는 원본이 리그별 기록으로 순위를 매겨, 표의 시즌 합계와 기준이 다를 수 있다.
- **구단 선수단 기록**: 그 구단에서 낸 기록만 들어가 리더보드의 시즌 합계와 다를 수 있다.
- **수상 기록의 포지션**: 선수의 주 포지션이라 수상 당시 포지션과 다를 수 있다.
- **`sWAR`**: 자체 계산한 간이 WAR라 공식 WAR와 다르다. 차이를 설명할 용어 설명 페이지가 아직 없다.
- **비시즌 로스터**: 원본에 남은 IL 표시가 실제 상태와 다를 수 있다.
- **마이너리그 순위 기호**(`*`, `^`, `#`, `@`): 뜻이 공개 문서로 확인되지 않아 보여주지 않는다.
- **Rookie 구장**: 좌표·수용 인원·펜스 거리가 대부분 없다. 파크팩터도 계산하지 않는다.

## 3. 운영

- **갱신 시각**: 리더보드는 `meta.json`의 실행 시각 하나만 보여준다. 일부 리그 수집이 실패해도 같은 시각이 표시되므로 리그별 갱신 시각이 필요하다.
- **자동 갱신 확인**: 동작 여부는 GitHub Actions 실행 기록으로만 확인한다. 실패 알림이 없다.
- **데이터 크기**: 로컬 `data/`가 약 444MB(2026-11-18, 캐시 포함)이고 파일이 수만 개다. 커리어·지명 캐시(`data/careers`, `data/drafts`)는 배포에서 빼고 있다. 저장소 크기가 계속 커지는지 지켜본다.
- **예약 실행 지연**: 매일 UTC 07:00 예약이 실제로는 16:04(11-18), 16:35(11-17) UTC에 시작됐다(약 9시간 늦음, `gh run list`로 확인). 경기 결과처럼 시각이 중요한 갱신을 넣기 전에 정각을 피한 시각·외부 호출(workflow_dispatch) 등을 검토한다 (PRD 15절).
- **공식 이동 반영 시차**: 이동 소식은 MLB 공식 처리 기록만 쓴다. 11-19 확인 시 원본 API에 11-18 이후 처리된 이동이 없어 그 뒤 보도된 FA 계약은 보이지 않는다. 화면에 "공식 기록 기준"과 마지막 반영일을 안내하는 것을 검토한다.
- **수동 실행이 필요한 스크립트**: `hof_votes.py`(명예의 전당 발표 뒤), `venue_photos.py`(구장이 바뀔 때), `recruitment.py --pipeline`은 자동 갱신에 없다.
- **공식 값 대조**: `validate.py`는 오차를 출력할 뿐 합격 판정을 하지 않는다.

## 4. 남은 계획

- **UI/UX 검토 후 남은 범위(2026-11-20)**: 리더보드 외 순위·유망주 등 다른 표의 키보드 정렬은 별도로 점검해야 한다. 리더보드 지표 설명은 짧은 정의만 제공하므로 계산식·해석 예시를 담은 용어 설명 페이지는 아래 계획에 유지한다. 실제 휴대폰·다크 모드·스크린리더 검증도 남아 있다.

- 계약 내용 확대: 1,220명의 기간·출처와 확인된 금액, 53명의 시즌별 기본 연봉을 제공한다(PRD 16.1절). 나머지 선수·미확인 연봉, 신규 계약·옵션 결과의 지속 반영이 남아 있다. 등록된 것은 계약 발표 기준이며 현재 유효 계약 전체 목록·실제 지급액·페이롤이 아니다. 특히 아쿠냐처럼 행사된 옵션은 조건 설명에 두고 최초 보장 기간·총액에는 더하지 않는다.
- 용어 설명 페이지 (PRD 4.5): 지표 공식, 리그 평균 100의 뜻, `sWAR`의 한계
- 화면 디자인 방향 정리 (PRD 12절 미정 사항)
- 선수 이름 한글 표기 (PRD 6.5): 한글 이름 표(`player_names_ko`)가 아직 없어 모든 선수가 원어 이름으로 나온다. MLB 주전급과 Top 100 유망주부터 채운다


## 5. 선수 맥락·경기·개인화의 남은 범위 (2026-11-19)

- 평균 비교는 MLB 전체 원시 기록 기준이다. AL/NL·구장 보정, MiLB 평균 비교와 과거 세이버 지표는 별도 작업이다. 옛 시즌에서 SF 등 원본 항목이 빠지면 OBP·OPS를 비워 둔다.
- 상황별 자료는 2024~2026 MLB만 수집했다. 더 오래된 시즌·MiLB는 미제공이며, API에 해당 상황 기록이 없는 선수는 '-'로 표시한다.
- 선수 리포트는 소수 지표의 평균 대비 차이 요약이다. 구종의 공식 사용률·구속·회전수·움직임은 별도 Statcast 표로 추가했다. 수비·주루·부상·미래 전망과 독자 구위 평가는 아직 없다.
- 경기 결과는 수집된 날짜만 조회한다. 초기 제공은 최근 3일과 화면 검증용 2025-09-28이며, 이전 경기일 전체 백필은 하지 않았다. 하루 두 번 수집이라 진행 중 경기 상태가 다음 실행 전까지 남을 수 있다.
- 뉴스는 MLB.com 공식 RSS 1개, 영어 제목 원문이며 독립적인 중요도 선정·한글 요약은 없다.
- 관심 설정은 같은 브라우저에만 저장되며 기기 간 동기화·푸시 알림은 없다.
- 09시·14시 예약 변경과 새 수집 단계의 실제 GitHub Actions 실행·배포는 아직 확인하지 않았다. 운영 중 지연·실패를 관찰해야 한다.

- Statcast는 2015~2026 MLB 정규시즌 집계를 제공한다. MiLB·2014년 이전·투구별 기록·최고 구속은 아직 수집하지 않는다. 측정값이 없는 타구와 소수 표본이 있으며, 구종은 원본 자동 분류와 반올림 사용률을 따른다. 개별 구종의 정확한 구수는 비율에서 역산하지 않는다.
- Statcast 수집은 공개 CSV 열과 페이지의 JSON 형식에 의존한다. 형식 변경·차단·빈 응답 시 기존 자료를 유지하며 마지막 정상 갱신 시각을 표시한다. 새 자동 갱신 단계의 실제 Actions 실행은 배포 후 확인해야 한다.

- **Statcast 평균 비교**: 반올림된 선수 집계의 가중 근사다. 타구 지표별 실측 공 수가 없어 BBE를 사용하고, 구종은 전체 구수×반올림 사용률 가중이다. 공식 공별 평균과 차이가 날 수 있다. 초기 PITCHf/x·Statcast 측정 누락도 남는다.
- **투구 위치·핫콜드존**: 2008~2026 MLB 정규시즌 19시즌을 제공한다. MiLB·2007년 이전은 미제공이다. 해외 개막전 등 경기 전체가 위치 미측정인 경우도 누락으로 보존한다. 타율·장타율은 위치가 확인된 타석 종료 공의 표본이며 표본·누락 수를 함께 제공한다. 전부 미측정이면 구역 표 대신 미제공 안내를 표시한다. 위치 분포는 20×20 격자 빈도이며 정확한 공별 좌표·목표 지점·제구 점수를 제공하지 않는다. 2026과 이전 측정 기준을 합칠 수 없다. 실제 Actions 운영·실제 휴대폰·다크 모드·스크린리더는 추가 확인해야 한다.
- **계약 전수 범위**: Cot's 30개 구단 공개 목록과 직접 검증 자료로 확대했지만 금액 미공개·선수 ID 연결 미확인·모든 과거 계약은 남는다. 조건부 연봉은 추정하지 않으며 월요일 자동 갱신을 연결했으며 실제 Actions 실행은 배포 후 확인해야 한다. 확인된 보장 계약과 구단 페이지의 계약 표제를 구별한다.
