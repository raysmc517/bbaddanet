# 변경점

사이트에서 바뀐 것을 날짜별로 짧게 적는다. 과정과 이유는 [개발 일지](devlog.md), 알려진 한계와 앞으로 고칠 것은 [보완점](improvements.md)에 둔다.
날짜는 한국 시간 기준이다. 데이터만 바뀐 일일 자동 갱신은 적지 않는다.

## 2026-11-23

### 추가
- 선수 상세 분석에 "지난 시즌과 비교" 버튼과 팝업: 기준 시즌과 이전 MLB 시즌의 기록·변화, 타구 질 또는 구종 사용률·구속 변화를 한 번에 표시

## 2026-11-22

### 변경
- 선수 상세의 상황별 성적을 한 표에서 주자 상황(득점권/평시)·투수 유형(좌투수/우투수, 투수는 좌타자/우타자)·홈/원정 세 표로 나누고 열 위치를 맞춤. 평시(주자 없음·1루 주자만) 기록 추가
- 투수 상황별 표도 타자와 같은 비율 열로 맞춤: 이닝·피OBP·피SLG·WHIP 추가. ERA는 원본이 홈/원정에만 있어 넣지 않음

### 추가
- 투수 투구 위치 구역에 핫콜드존 추가: 칸마다 구역 비율·투구 수·피안타율을 함께 보여주고 피안타율로 색칠(빨강 많이 맞은 구역, 파랑 덜 맞은 구역, 10타수 미만 회색)
- 투수·타자 구역 표와 투구 위치 분포 그림에 스트라이크존 경계를 굵은 선으로 표시(그림에서는 점 위에 그림)
- Statcast 구종·타구 표 위에 "지표 읽는 법" 펼침 설명 추가: 구속·회전수·수평 이동·IVB와 타구 속도·발사각 등이 높을수록 좋은지, 구종별로 유리한 방향의 경향

### 수정
- 선수 페이지의 스타일·상황별·Statcast 스크립트 버전 문자열을 올려 이전 캐시 파일이 남지 않게 함

## 2026-11-20

### 추가
- 탄착군·핫콜드존을 2008~2026 MLB 정규시즌 19시즌으로 확대: 44,630경기·원본 투구 기록 13,120,647건·선수 5,791명. 전수 검수 명령과 시즌별 검수 보고서 추가
- 선수 상세 분석에 투수 투구 위치 분포(탄착군)·구역별 비율과 타자 핫콜드존(타율·장타율·헛스윙률), 구종·좌우 필터·구역별 표본과 상세 수치 추가. 초기 2026 MLB 정규시즌 집계
- 분석 화면에 평균·상황별·Statcast·탄착군/핫콜드존 바로가기 추가
- 모바일 리더보드 핵심 기록/전체 기록 전환과 주소 복원. 핵심 보기에서 정렬 지표를 맨 앞에 표시하고 긴 이름을 줄이되 징계 별표 유지
- 선수 상세 상단에 최근 시즌 핵심 지표와 통산 요약 배치, 프로필·입단·수상 상세 펼쳐보기, 연도별 기록 바로가기
- 리더보드에 현재 정렬 기준·적용 조건 표시, 터치·키보드로 펼치는 지표 설명, 빈 결과의 조건 초기화와 전체 선수 검색 연결
- 선수 프로필에 상세 기록·분석 메뉴 추가. 리그 평균·리포트·상황별 기록·Statcast를 별도 주소로 분리하고 선택 시즌 유지
- 선수 페이지 분석 시즌에 Statcast 타구 속도·발사각·강한 타구%·배럴%·스위트스폿% 추가 (2015~2026 MLB)
- 구종별 사용률·평균 구속·회전수·수평 이동·수직 IVB와 움직임 비교 그림. km/h·mph, cm·in 병기
- Statcast에 선수·같은 시즌 MLB 가중 근사 평균·평균 대비 차이를 별도 열로 표시(타구 속도 차이도 km/h·mph 병기). 구종은 좌·우투와 구종별 비교
- 카일 슈와버 FA 계약·연도별 연봉 보완, MLB 30개 구단 공개 계약 자료로 1,220명 확대(명시적 기본 연봉 53명), 월요일 갱신
- 최신 시즌 타구·구종 집계를 09시·14시 자동 갱신에 포함

### 수정
- 타자 핫콜드존의 숫자·색상을 타율로 고정하고 장타율·헛스윙률은 선택 구역 아래에 표시
- 위치가 전부 미측정인 선수·조건은 0타수·0안타 표 대신 미제공 안내 표시. 옛 구종·원본 분류 코드의 한글 이름과 색상 보완
- 탄착군·핫콜드존 구역 상세에 타율·장타율(투수는 피안타율·피장타율)을 항상 표시하고 기존 타수·안타수·루타 유지
- 공통 메뉴의 전체 선수 검색을 첫 항목에 배치하고 모바일 메뉴 스크롤바 표시. 리더보드의 현재 시즌 이름 검색과 범위 구분
- 리더보드 열 정렬을 버튼으로 바꿔 Enter·Space 조작과 정렬 후 포커스 유지 지원
- 입단 경로 누락을 ‘2009년 이전 이동’으로 잘못 단정하던 표시 수정. 8,383명 점검 후 먼시를 포함한 마이너 FA 입단 1,943명 보완, 미확인은 별도 표시
