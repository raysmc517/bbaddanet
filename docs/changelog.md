# 변경점

사이트에서 바뀐 것을 날짜별로 짧게 적는다. 과정과 이유는 [개발 일지](devlog.md), 알려진 한계와 앞으로 고칠 것은 [보완점](improvements.md)에 둔다.
날짜는 한국 시간 기준이다. 데이터만 바뀐 일일 자동 갱신은 적지 않는다.

## 2026-11-18

### 추가
- MLB 구단 페이지에 공식 홈페이지 링크
- 선수 페이지 상단에 최근 시즌·통산 요약 표 (타격 요약에 삼진 SO 포함)
- 선수 연도별 표에 리그(AL·NL) 1위 기록 굵게 표시, 시즌별 수상 열
- 구단 연도별 성적 페이지(`franchise.html`): 1876년부터의 승패·순위·득실점·기대 승패·포스트시즌 결과
- 리그 이동 소식 페이지(`moves.html`), 선수 프로필의 "입단 경로"
- 명예의 전당 선출 방식·득표율·득표수·투표 차수 (출처: 위키백과)
- 국제 아마추어 계약 선수 298명의 계약일·구단, 그중 209명의 계약금 (출처: MLB Pipeline)
- MLB 구단 페이지에 구장 사진 (위키미디어 공용 자유 라이선스, 저작자·라이선스 표시)

### 변경
- 선수 연도별 표를 MLB.com Standard 표 형식과 순서로 바꿈. 투구 CG·SHO·SVO·NP·피안타율·GO/AO, 타격 TB·IBB·GO/AO 추가
- MLB와 마이너리그 기록이 모두 있는 선수는 기본으로 MLB 기록만 표시 (버튼으로 펼치기)
- 한 시즌 여러 팀 기록은 "N팀" 합계 행 아래에 팀별 행 표시
- 선수·구단 성적·수상 페이지의 시즌 선택을 시작·끝 기간 선택으로 바꿈
- 선수 페이지 수상 경력을 상별 카드로 바꿈
- MLB 구단 페이지에서 "선수 성적" 링크를 빼고 구단 역사에서 연도별 성적으로 연결

### 수정
- 통산 OPS를 MLB 공식 표기처럼 반올림한 출루율 + 장타율로 계산
- 파일 저장 중 OneDrive 잠금으로 실패하던 문제 (재시도)
- 모바일 화면에서 메뉴가 줄바꿈되던 문제

## 2026-11-17

### 추가
- MiLB High-A·Single-A 리더보드
- 선수 커리어: MLB 데뷔가 아니라 마이너리그를 포함한 프로 첫 시즌부터 표시
- 선수 프로필의 입단 정보 (지명 연도·라운드·전체 순위·계약금)
- 구단 목록·구단 상세 페이지: MLB 30개 구단과 산하 마이너리그 201개 구단, 구장 정보, 펜스 거리 도면
- 은퇴 선수 MLB 기록과 선수 검색 (29,806명). 2000년 이후 MLB 출전 은퇴 선수는 마이너리그 기록도 표시
- 수상 기록·명예의 전당 페이지(수상 19종), 구단 역사(우승, 영구결번, 명예의 전당, 소개 글)
- MLB 구단 로고, 선수 얼굴 사진 (MLB 공식 이미지 주소로만 표시)
- 선수 커리어 표의 시즌·레벨 필터, MLB·MiLB 통산 행
- 리그·지구별 순위 페이지 (MLB, AAA~Single-A, 기대 승패, 경기·잔여 경기)
- MLB 구단 선수단 페이지 (시즌별 선수단, 26인·40인 로스터, 부상자 명단, 선수 이동)
- 매일 한국 시간 16:00 자동 갱신과 GitHub Pages 배포

### 변경
- 선수 커리어 표를 같은 시즌 안에서 상위 리그순(MLB → AAA → … → Rookie)으로 정렬
- 리더보드 검색을 새로 시작하면 필터를 풀고, 이름의 악센트·대소문자를 무시
- 선수 페이지의 소속 팀을 구단 페이지로 연결

### 수정
- 과거 커리어의 팀 이름이 전체 이름과 약자로 섞이던 문제 (시즌·레벨별 약자로 통일)
- `--current-season` 옵션이 MiLB에서 무시되어 모든 시즌을 다시 받던 문제

### 보류
- KBO·NPB 수집: 공식 사이트의 이용 조건 때문에 승인 또는 다른 출처를 찾을 때까지 보류
